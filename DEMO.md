# Three-minute FundingLens demo

**0:00 — Problem.** “An RM can see portfolio value, yet still need to investigate which funds are accessible, when the client needs them, and which records disagree.”

**0:20 — Tran.** Open Tran. Point to university instalments with an unconfirmed next amount, the single linked capital-call exposure, the monthly SGD deposit, and the gated fund. Open the redemption source: a request is not confirmed cash. The app deliberately does not claim an established shortfall.

**1:00 — Draft and review.** Choose Draft funding questions. Explain the visible template/AI status. Edit the questions, inspect evidence, check the review attestation, and preview. Return to editing: any changed text requires review again. Nothing is sent.

**1:40 — Margarethe.** Show 71.46% equity versus the supplied 30% maximum and the recorded EUR 3.4m payment. Inspect source records. This is a mandate-review question, not a sell instruction or tax assessment.

**2:10 — Cheung.** Show the objective's USD 1.1m versus the planned record's USD 1.28m. The USD 180k disagreement prompts confirmation; neither record is silently selected as correct. Expand history to see portfolio context, not investment-return attribution.

**2:40 — Value.** “FundingLens puts the next client question beside the evidence needed to review it. Calculations are deterministic, wording is editable, and approval belongs to the RM.”

Success measure for a follow-up pilot: compare RM preparation time and factual-error rates against the original spreadsheets using the same cases. No impact metric is claimed yet.
